# ونسات (Wansat)

منصة تواصل اجتماعي سودانية كاملة، بالعربي RTL وباللهجة السودانية،
واجهة أولاً للتلفون (PWA). هوية أصلية خاصة بونسات — بدون أي كود أو شعار
أو أصول لفيسبوك.

## الاسم

الاسم في مكان مركزي واحد: [`src/lib/brand.ts`](src/lib/brand.ts)
(`APP_NAME` / `APP_NAME_EN` / `APP_TAGLINE`).
غيّر الاسم هناك فقط، والعنوان وصفحة الدخول والـ PWA manifest بتتغير معاه
تلقائياً. (اسم مجلد المشروع `sudan-social` واسم حزمة npm لا يظهران في الواجهة.)

## المميزات (كلها موجودة في السورس)

1. **حسابات وملفات شخصية** — تسجيل/دخول، ملف شخصي، نبذة، ولاية، صورة رمزية بالأحرف.
2. **الخلاصة** — إنشاء منشور نصي، إعجاب، تعليق، مشاركة (إعادة نشر)، حذف منشورك.
3. **أصدقاء ومتابعة** — طلبات صداقة (قبول/رفض)، قائمة أصدقاء، اقتراحات، متابعة/إلغاء.
4. **مجموعات** — إنشاء مجموعة، انضمام/مغادرة، خلاصة خاصة بالمجموعة، أعضاء.
5. **صفحات** — إنشاء صفحة، متابعة، خلاصة خاصة بالصفحة.
6. **قصص** — شريط قصص، عارض قصص، القصة تختفي بعد 24 ساعة (منطق الانتهاء موجود).
7. **دردشة** — قائمة محادثات 1:1، إرسال رسائل، بدء محادثة من ملف أي مستخدم.
8. **إشعارات** — قائمة إشعارات داخل التطبيق للإعجاب والتعليق وطلبات الصداقة، مع عدّاد غير المقروء.
9. **السوق** — قائمة إعلانات، إنشاء إعلان بالسعر والولاية، صفحة تفاصيل، مراسلة البائع.
10. **فعاليات** — قائمة فعاليات، إنشاء فعالية، مشاركة/إلغاء مشاركة (RSVP)، صفحة تفاصيل.
11. **بحث** — بحث في الناس والمجموعات والصفحات والمنشورات من شريط البحث العلوي.

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # تحقق من البناء
```

حساب تجريبي محلي: `demo@wansat.sd` / `demo`
(وحسابات البذرة الأخرى بنفس كلمة السر `demo`).

## الوضع الحالي: تجريبي محلي أم حي؟

**حالاً: تجريبي محلي.** بدون متغيرات Supabase، التطبيق يشتغل كاملاً
ببيانات محلية في متصفحك (localStorage) — لا سيرفر ولا حسابات حقيقية.
هذا مقصود حتى يُبنى ويُجرَّب بدون اعتماد على أي مشروع خارجي.

**للانتقال للحي:** أنشئ مشروع Supabase جديد (وليس مشروعاً موجوداً)،
نفّذ [`supabase/schema.sql`](supabase/schema.sql) فيه، ثم انسخ
`.env.example` إلى `.env.local` واملأ:

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
NEXT_PUBLIC_APP_URL=https://your-domain
```

ملاحظات صريحة عن حدود النسخة الحالية:

- كلمات السر في الوضع المحلي محفوظة في متصفحك فقط لغرض التجربة،
  وهي **ليست** بديلاً عن Supabase Auth في الإنتاج — لا تستخدم الوضع
  المحلي لبيانات حقيقية.
- الدردشة في الوضع المحلي حالة محلية (local state) وليست Realtime
  حقيقياً؛ عند تفعيل Supabase، تُفعَّل Realtime على جدول `messages`
  (انظر ملاحظات `schema.sql`).
- المنشورات والقصص نصية في v1؛ رفع الصور يحتاج bucket في Supabase
  Storage (موثق في `schema.sql`) ثم ربطه بمكوّن النشر.
- لا يوجد نشر حي بعد: لا Vercel ولا دومين ولا مشروع Supabase —
  هذه الثلاثة هي ما يبقى على المستخدم توفيره قبل النشر الحي.

## التقنية

Next.js 14 (App Router, TypeScript) + Supabase (Auth/Postgres/Storage/
Realtime) + Tailwind CSS. لا تعديل على أي مشروع آخر، ولا استخدام
لمفاتيح أو قواعد بيانات مشاريع أخرى.
